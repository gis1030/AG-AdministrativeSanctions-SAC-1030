## 🧭 Contents

- **Infractions dashboards** (one per year): monthly trends, categories, decisions, sources, neighbourhoods, streets, articles, heatmap month × weekday, billed vs collected, administrative delays and prescription risk.
- **Offenders dashboards** (one per year): offender type, gender, age bracket, residence (Schaerbeek · Belgium · abroad), neighbourhood, amounts paid, recidivism.
- **Map**: choropleth by block (BlockParcel) of the number of infractions, density, category, type, decision, amounts, offender profile and year-on-year change.

## 🔒 Data protection (GDPR)

Published data are **minimised**: no names, case or payment references, free-text comments, addresses or coordinates of offenders.
Offender identifiers are replaced by random numbers per year, ages are grouped in 5-year brackets, and municipalities or countries with few offenders are grouped as « Autres ».
The map only contains aggregates by block.

Data controller: **Commune de Schaerbeek** · Place Colignon · 1030 Brussels · Belgium
